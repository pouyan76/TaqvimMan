# تقویم من – پروژه اولیه اندروید

این یک پروژه پایه Android Studio با Kotlin است؛ APK از پیش ساخته‌شده نیست.

## باز کردن پروژه
1. Android Studio را نصب کنید.
2. پوشه `TaqvimManAndroid` را با گزینه **Open** باز کنید.
3. اجازه دهید Gradle همگام‌سازی و وابستگی‌ها را دریافت کند.
4. یک دستگاه اندرویدی یا شبیه‌ساز انتخاب و Run کنید.

## وضعیت قابلیت‌ها
- پوسته اولیه اپلیکیشن فارسی: موجود
- مجوز اینترنت و اعلان‌ها: تعریف شده
- سرویس Foreground مخصوص پخش رسانه: اسکلت اولیه موجود
- پخش واقعی فایل اذان: نیازمند انتخاب/افزودن فایل صوتی مجاز و اتصال URI به ExoPlayer
- زمان‌بندی دقیق نماز و اعلان هنگام بسته بودن برنامه: هنوز پیاده‌سازی نشده
- تقویم، هواشناسی و بازی ۵۰۰ مرحله‌ای: باید به رابط بومی و ذخیره‌سازی اپ اضافه شوند
- جدول رتبه‌بندی آنلاین: نیازمند بک‌اند و حساب کاربری

## نکته مهم
سرویس رسانه به‌تنهایی به معنی پخش خودکار اذان در زمان نماز نیست. برای محصول نهایی باید زمان‌بندی، دریافت مجوزهای لازم، مدیریت محدودیت‌های باتری و انتخاب فایل صوتی تکمیل و روی دستگاه‌های مختلف آزمایش شود.
